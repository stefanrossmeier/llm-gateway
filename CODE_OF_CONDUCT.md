# Code of conduct

Treat contributors and users with respect. Discuss technical decisions with
evidence, welcome corrections and focus criticism on work. Harassment,
discrimination, threats, deliberate humiliation and disclosure of another person's
private information are unacceptable.

This applies to project issues, pull requests and project spaces. Maintainers may
remove harmful content or restrict participation when necessary. Enforcement
should be proportionate, explain the behavior at issue and allow a good-faith
response where practical.

Report concerns privately through a maintainer-approved channel. If none exists,
request one through the maintainer's GitHub profile without posting sensitive
details. Maintainers should avoid conflicts of interest when handling reports.
This is an original project policy, not an adopted third-party covenant.
