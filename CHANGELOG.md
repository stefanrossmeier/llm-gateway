# Changelog

## 0.1.0a2

- Correct native-X billing to fetched post/profile rates and cumulative token usage;
  require explicit risk acceptance and distinguish allowances from enforced bounds.
- Preserve measured costs and uncertainty independently of output validation.
- Report consumed cost through authenticated API windows and local day/month grouping.
- Support explicitly authorized durable client run IDs with calendar-budget protection.
- Recover dashboard results by the original invocation ID after transport loss.
- Refresh public documentation, quickstart, deployment templates and release/security checks.

This is an alpha release. Exact artifact evidence and scoped live outcomes accompany
its release. It is not a claim of universal model/provider conformance or LTS support.
