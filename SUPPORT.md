# Support

Use this repository's GitHub Issues for non-sensitive bugs when available.
Include version/commit, Python/platform, a minimal synthetic config, safe error
code and reproduction. Remove keys, tokens, raw responses, real prompts and private
project identities. No response-time or service-level agreement is promised.

Read [installation](docs/INSTALLATION.md), [configuration](docs/CONFIGURATION.md)
and [operations](docs/OPERATIONS.md). For uncertain charges, preserve the ledger
and request/receipt IDs. Receipt lookup never repeats inference. Report security
issues through [SECURITY](SECURITY.md), not public issues.
