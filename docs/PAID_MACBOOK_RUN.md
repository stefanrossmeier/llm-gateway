# Local live acceptance

Use the same reviewed version, private configuration and stable request identities
on any supported development host. There is no embedded operator approval,
credential path or application deployment in this repository.

Prepare a concrete [paid acceptance proposal](PAID_ACCEPTANCE_PROPOSALS.md) and use
the installed [live-test tooling](LIVE_TEST_PLANS.md). Keep detailed reports and
ledgers private; publish only reviewed summaries without real prompts or secrets.
